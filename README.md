# homebrew-latex2arxiv

Homebrew tap for [latex2arxiv](https://github.com/YuZh98/latex2arxiv) — the arXiv submission pipeline.

## Install

```bash
brew tap YuZh98/latex2arxiv
brew install latex2arxiv
```

## Usage

```bash
latex2arxiv paper.zip --compile
latex2arxiv paper/ --dry-run
latex2arxiv --demo --compile
```

See the [main repo](https://github.com/YuZh98/latex2arxiv) for full documentation.
